# ADR-001

Title

Use Go as the Backend Platform

Status

Accepted

Context

The backend is responsible for business logic, authentication,
retail integrations and APIs.

Decision

Use Go.

Reason

High concurrency.

Excellent HTTP performance.

Strong type safety.

Fast deployment.

Simple binaries.

Consequences

Pros

Fast.

Reliable.

Easy deployment.

Cons

Smaller AI ecosystem.

Mitigation

Delegate AI runtime to Python.
