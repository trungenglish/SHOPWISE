Create a technical implementation plan for the SHOPWISE MVP.

## Objective

Implement an end-to-end AI Sales Agent for consumer electronics retail that demonstrates conversational shopping, explainable recommendations, product comparison, dynamic UI, and checkout readiness.

The implementation should prioritize simplicity, fast iteration, and demo readiness.

---

## Technology Stack

Frontend
- React
- Vite
- TypeScript
- TailwindCSS
- shadcn/ui
- TanStack Query
- Zustand

Backend
- Go 1.24
- Gin

AI Runtime
- Python
- FastAPI
- LangGraph

Communication
- REST API
- Server-Sent Events (SSE)

---

## Architecture

The MVP consists of only two backend runtimes.

React (Vite)

↓

Go Backend (Retail Module)

↓

Python AI Runtime

The Go Backend is responsible for:

- Conversation API
- Product Catalog
- Comparison
- Session
- Tool Registry
- Retail Provider
- Checkout Preparation
- Dynamic UI streaming
- Communication with AI Runtime

The Python AI Runtime is responsible for:

- Intent Understanding
- Planning
- Reasoning
- Tool Planning
- Recommendation
- Product Comparison
- Explainable Responses
- Dynamic UI Schema generation

## Data Source

Use mock retail data stored in JSON.

Prices must use Vietnamese Dong (VND).

Inventory is mocked.

Promotions are mocked.

---

## Architecture Constraints

Business logic belongs to the Go Backend.

AI Runtime must remain stateless.

The AI Runtime communicates with the backend only through Tool APIs.

The frontend renders only declarative UI Schema.

The AI never generates HTML or React components.
